# Security

This tool accepts local public scanner output only. Do not commit private data,
credentials, actual vehicle plates or downloaded user files. No outbound network
code is included. Report vulnerabilities through this repository's private
vulnerability reporting form: https://github.com/reihlinstinct/parcel-coverage-audit/security/advisories/new
Hebrew or English. No personal email is published on purpose. This repo serves no website,
so there is no security.txt here; the sibling project publishes one
(https://github.com/reihlinstinct/ginot-hair-plans/blob/main/docs/.well-known/security.txt). Do not include secrets in public issues.
